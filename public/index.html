新会话允许写入工作目录，额外权限会请求审批。模型默认沿用本机配置，也可在对话输入框底部选择。
HOW IT WORKS

连接的是你的电脑。

网页通过本机 Codex 共享后台，访问当前系统账号同一 CODEX_HOME 下的会话。网页不需要单独的模型 API Key。

  • 查看历史不会恢复或重跑任务。
  • 点击“接入实时会话”连接所选会话，接收实时事件和该连接上的审批；原客户端的待审批请求可能仍需在原处处理。
  • 输入框底部“＋ 图片”后可依次选择模型和推理强度，从下一条消息生效；默认沿用会话设置。执行中的会话请等待完成或先停止。
  • 点击“＋ 图片”、粘贴截图或拖入图片，每条消息最多4张。发送前可预览和删除。
  • 发送消息保留会话原有权限；审批仍需你明确确认。
  • 旧版独立进程占用的会话可能无法接入；先在原终端正常退出该会话，再在这里继续。
  • 网络断开不会自动重发消息。先查看历史，确认任务是否已经开始。
  • 归档会话可以查看；继续前请在原客户端恢复归档。

支持内网和 HTTPS 公网入口。实时连接只推送变化，切到后台会暂停网页连接；服务器上的 Codex 任务继续执行。
YOUR COMPUTERS

连接另一台电脑

每台电脑单独接入，继续使用各自账号下的项目和对话。

1. 添加后下载接入包，在目标电脑解压。

2. Windows 安装 Node.js LTS，重新打开 PowerShell，在解压目录执行：

powershell -NoProfile -ExecutionPolicy Bypass -File .\start-windows.ps1

Linux 执行 bash ./start-linux.sh。均需要 Node.js 22 或更新版本。

3. 按提示输入平时使用的 SSH 目标并登录，保持窗口运行，然后从侧栏选择这台电脑。

切换电脑会重新打开工作台，请先发送或保存正在编辑的内容。
